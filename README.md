# NVO987 Identity

## Overview

NVO987 Identity is the decentralized identity and digital presence layer associated with NVO987 and Nicholas Van-Orton.

The website provides a public and machine-readable identity environment connecting decentralized identity infrastructure, institutional activity, research identifiers, digital infrastructure, publishing, and related cultural projects.

Website:

https://identity.nvo987.us/

## Purpose

The Identity website serves as a central reference point for:

- decentralized identity
- DID Documents
- cryptographic identity verification
- institutional identity
- researcher identifiers
- NVO987 digital infrastructure
- decentralized web infrastructure
- independent publishing
- online bookstore
- cultural publications

The site is intended to provide both human-readable information and machine-readable identity resources.

## Identity Infrastructure

### DID Document

The DID Document is the machine-readable foundation of the decentralized digital identity associated with:

- NVO987
- Nicholas Van-Orton
- the association

It contains the identity identifier, public keys related to authentication, and service endpoints associated with the identity.

DID Document:

https://identity.nvo987.us/.well-known/did.json

### SHA-256 Hash

A SHA-256 hash is provided as an additional verification resource for the DID Document.

https://identity.nvo987.us/sha-256-did.txt

## Research Identifiers

### ORCID

ORCID iD:

### ISNI

The visual system uses:

- Inter for interface and informational typography
- Playfair Display for editorial and display typography

- minimal geometric identity mark
